## 핵심 기능 정의

1. **게시판 CRUD 작업을 수행할 수 있다.**
    - 게시글에 좋아요를 누를 수 있다.
    - 게시글에 댓글을 달 수 있다.
    - 게시글의 댓글에 댓글을 달 수 있다.
    - 댓글에 좋아요를 누를 수 있다.
2. **소셜 로그인으로 회원 가입 할 수 있다.**
    - 가입 정보를 볼 수 있다.
    - 프로필 사진을 변경하거나 수정 할 수 있다.
    - 닉네임을 변경 할 수 있다.
    - 비밀번호나 아이디를 찾을 수 있다.
    - 비밀번호를 변경할 수 있다.
